BAGIAN 2: ARSITEKTUR DAN KONFIGURASI SISTEM
================================================================================

MODEL E-1 — Model Hibrida (yang diusulkan penelitian ini):
- Backbone: EfficientNet-B0 pretrained ImageNet
- Feature dim backbone: 1280-dim
- Fitur DCT: 192-dim (mean + variance + skewness dari koefisien DCT blok 8x8 pada kanal Y)
- Input head classifier: 1280 + 192 = 1472-dim
- Head: Linear(1472, 2) → Softmax
- Total parameter: 4.010.494
- Parameter head: 2.946
- Ukuran checkpoint: 46.3517 MB
- Checkpoint tersimpan: best_efficient_dct.pth

MODEL E-2 — Model Baseline (pembanding):
- Backbone: EfficientNet-B0 pretrained ImageNet (identik dengan E-1)
- Feature dim: 1280-dim
- Tidak menggunakan DCT
- Input head classifier: 1280-dim
- Head: Linear(1280, 2) → Softmax
- Total parameter: 4.010.110
- Parameter head: 2.562
- Ukuran checkpoint: 46.3502 MB
- Checkpoint tersimpan: best_efficient_no_dct.pth

Konfigurasi Pelatihan (sama untuk keduanya):
- Optimizer: AdamW
- LR backbone: 3e-5 (initial)
- LR head: 5e-4 (initial)
- Weight decay: 1e-2
- Scheduler: CosineAnnealingLR (T_max=45, eta_min=1e-7)
- Epochs total: 45
- Loss: CrossEntropyLoss berbobot kelas
  → Bobot REAL: 1.562500 (kelas minor)
  → Bobot FAKE: 0.735294 (kelas mayor)
- Batch size: 32
- Device: CPU (FORCE_CPU=1)
- Framework: PyTorch 2.11.0+cu130

Strategi Augmentasi (3 fase):
- Fase Light (epoch 1–9): Resize 224x224, RandomHorizontalFlip, ColorJitter ringan
- Fase Medium (epoch 10–19): tambah RandomRotation, BrightnessContrast
  → LR direset: backbone=1e-5, head=2e-4 (untuk menghindari LR=0 di awal fase)
- Fase Heavy (epoch 20–45): tambah RandomResizedCrop, CutOut/Erasing
  → LR direset kembali: backbone=1e-5, head=2e-4
- Early stopping: patience=15, min_epoch=25 (keduanya tidak berhenti sebelum epoch 45)

Preprocessing DCT (precomputed, disimpan sebagai file .npy):
- Konversi RGB → YCbCr, ambil kanal Y (luminansi)
- Bagi gambar menjadi blok non-overlapping 8x8 piksel
- Hitung 2D DCT (scipy.fft.dctn) pada setiap blok, norm="ortho"
- Untuk 64 koefisien per blok, hitung statistik agregat: mean, variance, skewness
- Concatenate: [mean_64, var_64, skew_64] = vektor 192-dim
- Normalisasi per-sampel: z-score (mean=0, std=1)

Eval Transform (deterministik, untuk evaluasi):
- Resize(224, 224)
- Normalize(mean=[0.485, 0.456, 0.406], std=[0.229, 0.224, 0.225])
- ToTensorV2()

BAGIAN 5: UJI SIGNIFIKANSI STATISTIK — DeLONG'S TEST
================================================================================

Metode: DeLong's test untuk dua ROC AUC yang berkorelasi (Sun & Xu, 2014)
Justifikasi: Digunakan karena kedua model dievaluasi pada sampel validasi yang SAMA
             (N=5.625 sampel validasi, kondisi Clean/tanpa degradasi)

Hasil:
  AUC E-1 (clean validation)  : 0.994530
  AUC E-2 (clean validation)  : 0.991491
  AUC Diff (E1 - E2)           : +0.003039
  Z-statistic                  : 7.688240
  P-value                      : < 0.00000001 (praktis nol)
  Kesimpulan statistik         : SIGNIFIKAN (p < 0.05)

Interpretasi penting untuk BAB 4:
Perbedaan AUC sebesar 0.003 antara E-1 dan E-2 SIGNIFIKAN secara statistik
(karena n besar), NAMUN tidak signifikan secara praktis. Dosen penguji perlu
diyakinkan bahwa delta 0.003 tidak bermakna dalam konteks deployment nyata.
Kalimat yang tepat: "Meskipun uji DeLong menunjukkan signifikansi statistik,
selisih AUC sebesar 0.003 tidak memiliki implikasi praktis yang bermakna
dalam konteks penerapan sistem deteksi deepfake."

Sebaliknya, CNN murni (E-2) masih dapat mengekstraksi ciri-ciri deepfake
dari sisa area wajah yang tidak tertutup (dahi, telinga, dagu, dll.).

6. Occlusion dalam augmentasi pelatihan: Occlusion tidak dimasukkan sebagai
   skenario augmentasi selama training, sehingga model tidak pernah "berlatih"
   menghadapi kondisi tersebut.

BAGIAN 13: CATATAN TEKNIS TAMBAHAN
================================================================================

Mengapa Best Checkpoint Epoch 8/9, Bukan Epoch Terakhir (45)?
- Epoch 8/9 terjadi di akhir Fase Light augmentation
- Masuk ke Fase Medium (epoch 10) langsung menurunkan performa validasi ~2%
  karena augmentasi lebih keras mengubah distribusi input secara signifikan
- Ini BUKAN overfitting — training loss pun naik di epoch 10
- Heavy augmentation (epoch 20+) makin menurunkan val AUC ke ~0.91
- Perbandingan best vs latest: best AUC=0.989, latest AUC=0.978 → best jelas superior
- Strategi pemilihan checkpoint berdasarkan val AUC terbukti tepat

Mengapa Accuracy E-1 < E-2 Meski AUC Hampir Sama?
- E-1 sangat agresif dalam mempertahankan REAL (Rec REAL=0.986)
- Konsekuensinya: lebih banyak FAKE yang "lolos" sebagai REAL (Rec FAKE=0.893)
- E-2 lebih seimbang: Rec FAKE=0.963, Rec REAL=0.940
- Dengan test set yang sangat imbalanced (FAKE=68%), pola E-1 menghasilkan
  lebih banyak kesalahan secara absolut → accuracy lebih rendah meski diskriminasi
  (AUC) hampir sama

Mengapa Evaluasi Robustness Menggunakan 2000 Sampel (Bukan Semua 5625)?
- Evaluasi penuh 5625 sampel × 15 kondisi × 2 model di CPU ≈ 10+ jam
- 2000 sampel tersampel stratifikasi (REAL:FAKE=640:1360) sudah cukup stabil
  untuk estimasi AUC (error < 0.002 dibanding full set)
- Seed sampling=42 memastikan reproducibility
